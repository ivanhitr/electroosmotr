# Как выложить «Электроосмотр» на GitHub и получить ссылку

Инструкция на 5–10 минут. Нужен только браузер, устанавливать программы не надо.
В конце получится ссылка вида `https://ваш-логин.github.io/electroosmotr/`, которую можно отправлять кому угодно.

---

## Шаг 0. Подготовьте папку

В папке `github-pages` лежит всё, что нужно:

```
index.html              ← приложение
README.md               ← описание для страницы репозитория
ИНСТРУКЦИЯ.md           ← этот файл
vendor/jszip.min.js     ← библиотека ZIP
vendor/xlsx.full.min.js ← библиотека Excel
.nojekyll               ← технический файл, необязательный
```

Проверьте, что папка `vendor` лежит **рядом** с `index.html`, а не внутри неё.

---

## Шаг 1. Создайте репозиторий

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите **зелёную кнопку «+»** в правом верхнем углу → **New repository**.
3. Заполните:
   - **Repository name**: `electroosmotr` (латиницей, без пробелов — можно любое другое имя);
   - **Description**: `Фотофиксация осмотра объектов` (по желанию);
   - выберите **Public** — для бесплатного GitHub Pages репозиторий должен быть публичным;
   - галочки `Add a README file`, `.gitignore`, `license` **не ставьте**.
4. Нажмите **Create repository**.

Откроется пустая страница репозитория.

---

## Шаг 2. Загрузите файлы

1. На странице репозитория нажмите ссылку **«uploading an existing file»**
   (или **Add file → Upload files**).
2. Откройте на компьютере папку `github-pages` и **перетащите в окно браузера всё её содержимое**:
   `index.html`, `README.md`, `ИНСТРУКЦИЯ.md` и **папку `vendor`**.
   - Перетаскивать нужно именно файлы и папку, а не саму папку `github-pages`.
   - Если папка `vendor` не переносится — сначала загрузите файлы и нажмите **Commit changes**,
     затем ещё раз **Add file → Upload files** и перетащите папку `vendor` отдельно.
3. Дождитесь, пока все файлы появятся в списке (их должно быть 4 файла + папка `vendor`).
4. Внизу нажмите **Commit changes**.

> Файл `.nojekyll` может быть невидимым в проводнике. Если он не загрузился — ничего страшного,
> приложение работает и без него. Если хотите добавить: **Add file → Create new file**,
> имя файла `.nojekyll`, содержимое оставьте пустым, **Commit changes**.

---

## Шаг 3. Включите GitHub Pages

1. В репозитории откройте вкладку **Settings** (справа вверху).
2. В левом меню выберите **Pages**.
3. В блоке **Build and deployment**:
   - **Source**: `Deploy from a branch`;
   - **Branch**: `main` и папка `/ (root)`;
   - нажмите **Save**.
4. Подождите 1–2 минуты и обновите страницу.
   Появится надпись: **«Your site is live at https://<логин>.github.io/<репозиторий>/»**.
5. Нажмите на ссылку — приложение откроется.

> Если вместо ссылки написано «Your site is currently being built» — подождите ещё минуту.
> Если появилась ошибка — проверьте, что `index.html` лежит в **корне** репозитория,
> а не внутри папки.

---

## Шаг 4. Проверьте на телефоне

1. Откройте полученную ссылку **в Chrome** (Android) или **в Safari** (iPhone).
   Не открывайте её из Telegram, VK, почты или другого встроенного браузера — они часто блокируют камеру.
2. Нажмите «Начать осмотр» → заполните параметры → «Начать осмотр».
3. Нажмите «Снимок» — браузер спросит доступ к камере, выберите **Разрешить**.
4. Должно открыться живое превью с круглой кнопкой затвора. Снимайте сколько нужно:
   счётчик вверху растёт, миниатюры появляются внизу.
5. Закройте камеру крестиком — фото останутся в осмотре.
6. «Выгрузить отчёт» → «Сформировать» — скачается ZIP с таблицей Excel и папками фото.

Если камера не запустилась — приложение автоматически предложит системную камеру.
Но по ссылке `https://` должна работать именно встроенная.

---

## Шаг 5. Раздайте ссылку

Скопируйте адрес из строки «Your site is live at …» и отправьте сотрудникам любым способом.

- Устанавливать ничего не нужно: достаточно открыть ссылку в браузере телефона.
- У каждого пользователя свои данные: фото хранятся в его браузере и попадают только в его архив.
- На сервере GitHub лежит лишь сам файл приложения, никаких фотографий.

Можно добавить страницу на главный экран телефона: в Chrome — меню «⋮» → **Добавить на главный экран**.
Тогда приложение будет открываться как обычное, по иконке.

---

## Как обновить приложение

1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите новый `index.html` (и папку `vendor`, если она менялась).
3. **Commit changes**, подождите минуту.
4. Обновите страницу на телефоне (потяните вниз или закройте/откройте вкладку).
   У других пользователей обновится при следующем открытии ссылки.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| «404 There isn't a GitHub Pages site here» | Pages ещё собирается (подождите 2 минуты) или в Settings → Pages не нажали Save |
| Открывается список файлов вместо приложения | `index.html` лежит не в корне репозитория — переместите его в корень |
| «Живое превью недоступно» по ссылке https | Браузер запретил камеру: значок замка в адресной строке → Разрешения → Камера → Разрешить, затем перезагрузить |
| Камера не запускается только в Telegram/VK | Откройте ссылку в Chrome: меню «⋮» → «Открыть в браузере» |
| Отчёт не скачивается | Проверьте, что в браузере разрешены загрузки и есть свободное место |
| «Нет доступа к библиотекам ZIP/XLSX» | Нет папки `vendor` и нет интернета — загрузите папку `vendor` в репозиторий |
| Фото пропали после перезагрузки | Не хватило места в браузере или открыт режим инкогнито; по ссылке https автосохранение работает |

## Частые вопросы

**Ссылка публичная?**
Да. Сайт на GitHub Pages виден всем, у кого есть адрес. При этом данные осмотров никуда не отправляются —
они живут в браузере пользователя.

**Можно сделать репозиторий приватным?**
На бесплатном тарифе GitHub Pages работает только для публичных репозиториев. Приватность даёт
только платный план GitHub Enterprise.

**Сколько это стоит?**
GitHub Pages бесплатен для публичных репозиториев. Ограничения: ~1 ГБ на сайт и ~100 ГБ трафика в месяц —
для одного HTML-файла это с огромным запасом.

**Нужен ли свой домен?**
Нет. Если захотите — Settings → Pages → Custom domain.

**Можно без GitHub?**
Да, подойдёт любой статический хостинг: [Netlify Drop](https://app.netlify.com/drop) (перетащить папку,
получить ссылку сразу), Cloudflare Pages, Vercel. Главное — адрес должен начинаться с `https://`,
иначе браузер снова запретит встроенную камеру.
